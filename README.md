### Method 2: Build from Source Code

This method requires a computer with Android Studio.

1. Open this GitHub repository.
2. Click **Code → Download ZIP**.
3. Extract the ZIP file.
4. Open Android Studio.
5. Select **Open** and choose the Android project folder.
6. Allow Gradle to sync and download dependencies.
7. Build and run the app on an emulator or a connected Android device.

The exact steps depend on the project's structure and configuration.

## 🧠 How to Build Your Own Android App

### Step 1: Open Google AI Studio

Visit [Google AI Studio](https://aistudio.google.com/) and sign in.

### Step 2: Open Build Mode

Choose the available app-building workflow and select Android development if that option is available.

### Step 3: Describe Your Idea

Example prompt:

> Create a simple Android chess game with an interactive chessboard, a clean interface, and a restart button. Generate the project and help me test the main features.

### Step 4: Generate the App

Let the AI generate an initial implementation. Review the preview and check whether it meets your requirements.

### Step 5: Refine the App

Use follow-up prompts to improve the interface, investigate bugs, and add features.

### Step 6: Test the App

Test the main functions, check for unexpected behaviour, and verify the application on a real Android device.

### Step 7: Export and Install

Use the supported export or Android installation workflow. To distribute the app through GitHub, build and test an APK and attach it to a GitHub Release.
